# Ursprüngliche Git-Historie

Dieser GitHub-Import enthält den vollständigen Quellstand von MediathekAtlas 0.4.7 (ursprünglicher Commit `b5097cb`). Der direkte Git-Transport hatte keine Anmeldedaten; deshalb erfolgte der Upload über die GitHub-API als Snapshot.

`MediathekAtlas-history.bundle` enthält die ursprüngliche Git-Historie mit 20 Commits auf main, einschließlich der originalen Commit-IDs. Wiederherstellung in ein separates Verzeichnis:

```sh
git clone archive/MediathekAtlas-history.bundle MediathekAtlas-history
```

Das installierbare macOS-Paket liegt unter [downloads/MediathekAtlas_v0.4.7_macOS.zip](../downloads/MediathekAtlas_v0.4.7_macOS.zip). Es enthält App, Quellcode, Diagnosehilfe und Git-Bundle. Lokale Katalogdatenbanken, Schlüssel und persönliche Downloads sind kein Bestandteil des Repositories.
